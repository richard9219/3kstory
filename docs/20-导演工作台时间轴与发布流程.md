# 20 导演工作台时间轴与发布流程

本文档说明可执行时间轴、转场合成、发布门禁与平台发布的最新闭环。

## 1. 目标

- 把分镜从静态管理升级为可执行时间轴。
- 把导出从基础拼接升级为按转场类型渲染。
- 把导演版导出接入发布前质量门禁与平台发布流程。

## 2. 执行对象

`StoryboardShot` 作为时间轴单元，核心字段：

- `track_index`: 轨道编号
- `timeline_start_ms`: 起始时间
- `timeline_duration_ms`: 镜头时长
- `transition_type`: 转场类型（`cut`/`fade`/`wipe`/`match`）
- `transition_duration_ms`: 转场时长
- `clip_status`: 镜头素材状态
- `clip_video_url`: 镜头素材地址
- `clip_score`: 镜头质量分

## 3. 导演版合成策略

合成流程：

1. 收集已完成镜头（`clip_status=completed` 且有 `clip_video_url`）。
2. 归一化素材（统一像素格式、音频采样率，缺音轨补静音）。
3. 按镜头顺序构建 ffmpeg filter graph：
   - 视频：`xfade`
   - 音频：`acrossfade`
4. 按 `transition_type` 映射转场：
   - `cut` -> 极短过渡
   - `fade` -> `fade`
   - `wipe` -> `wipeleft`
   - `match` -> `smoothleft`
5. 输出导演版 `VideoTask(task_type=director_cut)`。

导出任务写入：

- `quality_score`
- `quality_threshold`
- `quality_gate_passed`
- `quality_gate_reason`
- `render_mode=transition_graph`

## 4. 发布前门禁

门禁阈值统一复用后端配置：

- `PUBLISH_QUALITY_THRESHOLD`

校验规则：

- `quality_score >= quality_threshold` 通过。
- 否则返回阻断原因，不允许发布。

## 5. 平台发布接入

发布前置条件：

1. 导演版门禁通过。
2. 用户已绑定目标平台账号（抖音/小红书/B站/微博）。

发布动作会调用平台 uploader 适配层进行真实上传，并把回执写入历史记录与导演版任务输出：

- 平台上传回执：`receipt_id`、`request_id`、`http_status`、`remote_video_id`
- 平台返回原始摘要：`raw_body`
- 状态：`success` / `failed`，失败原因保留在 `error_msg`

导演版任务输出中同步记录：

- `published_platforms.<platform>.published_at`
- `published_platforms.<platform>.status`
- `published_platforms.<platform>.receipt_id`
- `published_platforms.<platform>.http_status`
- `published_platforms.<platform>.remote_video_id`
- `last_publish_platform`
- `last_publish_at`

发布历史表：`director_publish_records`

- 记录首次发布与重试链路（`attempt_no`、`retried_from_id`）
- 支持失败重试后的结果追踪

## 6. 接口清单

- `GET /api/v1/projects/:id/storyboard-timeline`
- `PATCH /api/v1/projects/:id/storyboard-shots/:shotID`
- `POST /api/v1/projects/:id/storyboard-shots/:shotID/generate`
- `POST /api/v1/projects/:id/storyboard-shots/:shotID/regenerate`
- `POST /api/v1/projects/:id/storyboard-timeline/render`
- `GET /api/v1/projects/:id/storyboard-timeline/exports/:exportID`
- `POST /api/v1/projects/:id/storyboard-timeline/exports/:exportID/auto-publish`
- `POST /api/v1/projects/:id/storyboard-timeline/exports/:exportID/publish`
- `GET /api/v1/projects/:id/storyboard-timeline/publish-history`
- `POST /api/v1/projects/:id/storyboard-timeline/publish-history/:recordID/retry`

## 7. 前端交互约束

- 时间轴镜头卡支持拖拽：
  - 横向拖动映射起始时间
  - 在不同轨道上释放映射轨道编号
- 时间轴支持可视化轨道尺与吸附规则：
  - 网格吸附（当前默认 500ms）
  - 同轨碰撞检测
  - 自动避让（冲突时向后推移到可用空位）
- 起始时间编辑以拖拽为主，表单仅保留展示。
- 导演版卡片内提供：
  - 门禁校验
  - 平台选择
  - 发布按钮
- 新增发布历史页：按平台展示回执、失败原因、重试入口

## 9. 导演风格模板

导演工作台已内置首批风格模板（可一键注入运镜、情绪与提示词前缀）：

- 黑泽明
- 张艺谋
- 陈凯歌
- 冯小刚

模板用于“自动化导演处理”的快速起步，后续可扩展为 Agent 化的风格参数编排器。

## 8. 已知限制

- 若本机缺少 `ffmpeg/ffprobe`，导演版转场合成不可用。
- 极端素材编码差异可能导致合成失败，建议先做素材归一化。
