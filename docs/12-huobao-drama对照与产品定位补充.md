# 12 huobao-drama 对照与产品定位补充

本文档用于回答三个问题：

1. `huobao-drama` 对三千影视当前构建有什么可补充
2. 四条生产线是否覆盖主流视频领域
3. 三千影视如何明确“类似 Cursor 的 AI 视频工具”定位

## 1. 对照结论

参考项目：`chatfire-AI/huobao-drama`

可借鉴点：

- 端到端工作流意识强：从剧本、角色、分镜到视频合成有完整链路
- 资产管理颗粒度高：角色、场景、素材可沉淀复用
- 任务进度跟踪清晰：生成任务状态和资产管理形成闭环
- 部署与运维实用性强：文档覆盖 Docker、本地、权限问题

不建议照搬点：

- 技术栈和架构分层不同，直接迁移会增加系统复杂度
- 其产品重心偏“短剧生产平台”，而三千影视定位是“多模型 AI 视频工具底座”

对三千影视的直接补充建议：

1. 模型中心要成为一级能力，而不是配置页
2. 资产中心和分镜中心要先打通“可存、可查、可复用”闭环
3. 任务中心要补“失败类型统计 + 自动重试策略”
4. 工作流层要长期规划为可编排（节点式或模板式）

## 2. 四条生产线覆盖评估

当前四条生产线：

- 影视解说
- AI 短剧
- AI 电影
- 广告与品牌内容

覆盖度评估：

- 对内容生产主流赛道覆盖较高，已覆盖大多数商用短视频需求
- 对“教育培训、知识IP、企业内训、新闻资讯、直播切条”这类赛道尚未显式命名

建议：

- 保留当前四条主线不变（便于产品主叙事简洁）
- 在官网和控制台中把“行业场景”作为次级维度补充：

  - 教育与知识内容
  - 企业培训与品牌传播
  - 新媒体资讯与直播二创

即：四条主生产线 + 多行业场景映射。

## 3. Cursor 型 AI 视频工具定位

三千影视的核心不是“某一个视频模型”，而是“模型编排与生产协同能力”。

建议统一表述：

- 三千影视是类似 Cursor 的 AI 视频工具
- 面向用户提供“多模型接入 + 任务编排 + 资产复用 + 分发闭环”

能力拆解：

1. 模型接入层
2. 任务编排层
3. 资产与分镜层
4. 发布与复盘层

用户价值表达：

- 像 Cursor 让开发者自由切换模型一样，三千影视让创作者自由切换并组合视频模型
- 用户不用关心底层 API 差异，只关注创作目标和质量结果

## 4. 当前版本落地要求

当前版本建议优先级：

1. 模型中心：真实配置状态 + 健康检查 + provider 优先级
2. 资产中心：角色资产 + 提示词模板先落表
3. 分镜中心：镜头结构 + 项目镜头列表 + 场景引导初始化

完成这三项后，三千影视就从“概念化控制台”进入“可持续扩展的产品底座”阶段。
