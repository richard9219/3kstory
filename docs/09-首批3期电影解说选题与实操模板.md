# 09 首批 3 期电影解说选题与实操模板

本文档用于帮助 3kstory 在当前本地生产阶段，快速做出首批 3 期可发布的电影解说视频。

目标不是一开始就做“最复杂、最完整”的解说，而是先做出：

- 能稳定产出
- 素材容易准备
- 观众容易看懂
- 便于测试风格和完播率

---

## 1. 首批选题原则

首批 3 期建议遵循这 4 个原则：

- 选你熟悉的电影，方便写准确简介
- 选剧情主线清晰、人物冲突强的电影
- 选容易剪出 30 到 90 秒高密度内容的电影
- 先做“单主题解说”，不要一上来讲完整部电影

更适合首批测试的类型：

- 犯罪 / 悬疑
- 黑色幽默
- 强反转
- 强情绪冲突

不建议首批就做：

- 世界观太复杂的科幻片
- 多线叙事太强的电影
- 太依赖细节铺垫的文艺片
- 需要大量版权高风险片段的热门新片

---

## 2. 推荐的首批 3 期结构

### 第 1 期：人物冲突型

- 目标：验证“剧情简介 -> 自动解说稿 -> 稳定成片”是否顺
- 重点：角色对立清晰，旁白容易讲
- 推荐题材：黑帮、权力、骗局、对抗

### 第 2 期：悬念反转型

- 目标：验证“悬念开头”对完播率的帮助
- 重点：前 3 秒强钩子
- 推荐题材：反转、骗局、逃生、心理战

### 第 3 期：情绪共鸣型

- 目标：验证“情绪向文案”是否更容易互动
- 重点：少讲设定，多讲情绪和选择
- 推荐题材：遗憾、背叛、成长、牺牲

---

## 3. 第 1 期模板：强冲突人物局

### 3.1 推荐片型

可参考这类片子：

- 《让子弹飞》
- 《无间道》
- 《教父》

建议优先从你最熟悉的一部开始，不一定非要照这个片名。

### 3.2 这期要讲什么

不要试图讲完整部电影。

建议只讲一个核心冲突：

- 主角如何进入局面
- 对手如何压制他
- 主角如何反击

### 3.3 简介写法模板

把简介控制在 80 到 180 字，尽量只写主线，不写太多支线。

可直接套用：

```text
这部电影讲的是一个极有手段的主角，进入一个被强势反派控制的地方。表面上双方在合作，实际上从一开始就在互相试探。反派靠权力、金钱和人脉压制所有人，主角则用更聪明的方式一步步反击。整部电影的看点不只是斗狠，而是看两个聪明人如何在规则之内外彼此拆招。
```

### 3.4 素材准备建议

推荐准备 3 段素材：

- 角色首次亮相
- 正面对峙
- 局势反转或压迫感最强的片段

素材要求：

- 总素材时长先准备 1 到 3 分钟
- 画面尽量有人物正脸、对峙、动作变化
- 少用全黑场、纯对白长镜头

### 3.5 参数建议

- 风格：`深度分析`
- 时长：`60` 秒
- 声音：`female_cn`
- 画幅：
  - 横版测试：`16:9`
  - 短视频测试：`9:16`
- Provider：`local`

### 3.6 推荐开场句方向

可参考这种节奏：

```text
这个男人刚进城，就盯上了这里最有权势的人。
```

或：

```text
这不是普通的斗狠，而是两个聪明人之间的极限试探。
```

### 3.7 这期的观察重点

- 观众是否能快速看懂人物关系
- 解说稿会不会太绕
- 字幕和画面是否匹配

---

## 4. 第 2 期模板：悬念反转局

### 4.1 推荐片型

可参考这类片子：

- 《看不见的客人》
- 《致命 ID》
- 《消失的爱人》

### 4.2 这期要讲什么

这期不要从背景讲起，直接从“最反常的一件事”切入。

建议结构：

- 开头抛出异常事件
- 中段逐步补信息
- 结尾留一点反转感，不要一次讲透

### 4.3 简介写法模板

```text
这部电影表面上是一起普通案件，但越往后看越会发现，所有人都在隐藏真正的事实。主角以为自己掌控了局面，实际上每一步都可能正中别人的陷阱。它最厉害的地方不是单纯反转，而是你以为真相已经出现的时候，电影才刚刚开始翻盘。
```

### 4.4 素材准备建议

推荐准备 3 到 4 段素材：

- 异常事件发生
- 主角焦虑或被追问
- 关键人物说出模糊信息
- 最后一个似真似假的“真相时刻”

素材要求：

- 多准备一些表情特写
- 多准备密闭空间、 interrogation、车内、房间类镜头
- 少用动作场面，重点突出悬念感

### 4.5 参数建议

- 风格：`搞笑` 或 `深度分析`
- 首轮建议：先用 `深度分析`
- 时长：`45` 秒
- 声音：`male_cn`
- 画幅：`9:16`
- Provider：`local`

### 4.6 推荐开场句方向

```text
一觉醒来，这个男人发现自己成了整场骗局里最危险的那个人。
```

或：

```text
如果所有证据都指向你，那最可怕的事，可能不是你有罪，而是有人比你更早布好了局。
```

### 4.7 这期的观察重点

- 前 3 秒有没有钩子
- 45 秒内信息密度是否足够
- 观众会不会想看后续第二期

---

## 5. 第 3 期模板：情绪共鸣局

### 5.1 推荐片型

可参考这类片子：

- 《忠犬八公》
- 《海边的曼彻斯特》
- 《这个杀手不太冷》

### 5.2 这期要讲什么

这期重点不放在复杂剧情，而是放在人物选择和情绪代价。

建议结构：

- 先用一句话定义角色处境
- 再讲一个让人心疼的选择
- 最后收在一句能引发评论的话上

### 5.3 简介写法模板

```text
这部电影最打动人的地方，不是剧情有多复杂，而是主角明明很想改变命运，却始终被现实推着往前走。他不是没有机会，而是每次做出选择，都要付出非常沉重的代价。真正让人难受的，不是结局本身，而是你能理解他为什么只能这么选。
```

### 5.4 素材准备建议

推荐准备 3 段素材：

- 主角相对平静的日常
- 情绪爆发或沉默承受
- 最后能留下余味的镜头

素材要求：

- 镜头变化不必太快
- 允许更多停顿和表情
- 尽量保留能承载情绪的中近景

### 5.5 参数建议

- 风格：`情感向`
- 时长：`75` 秒
- 声音：`female_cn`
- 画幅：`16:9`
- Provider：`local`

### 5.6 推荐开场句方向

```text
有些电影最狠的地方，不是让你震惊，而是让你慢慢理解一个人为什么会被生活逼成这样。
```

或：

```text
这个角色最让人难受的地方，是他明明没有做错什么，却还是失去了最重要的东西。
```

### 5.7 这期的观察重点

- 评论区会不会出现共鸣类留言
- 情感向解说是否更容易被看完
- 旁白节奏会不会太平

---

## 6. 三期通用的素材准备法

如果你只想快速开干，可以统一按这个方法准备素材：

### Step 1：先定主题

每期只选一个主题：

- 智斗
- 反转
- 遗憾
- 复仇
- 欺骗
- 牺牲

### Step 2：只截 3 到 4 段素材

每段控制在：

- 8 到 20 秒

总素材建议：

- 60 秒视频：准备 1 到 2 分钟素材
- 45 秒视频：准备 50 到 90 秒素材
- 75 秒视频：准备 1.5 到 3 分钟素材

### Step 3：保证镜头层次

素材里尽量混合：

- 人物特写
- 对峙画面
- 情绪反应
- 环境镜头

### Step 4：避免这些素材

- 长时间纯黑场
- 完全听不懂发生了什么的跳剪
- 太多同一场景的重复对白
- 没有人物表情变化的远景

## 7. 三期通用的简介填写法

当前系统对简介依赖很高，所以简介最好按下面结构写：

### 模板结构

1. 主角是谁
2. 他处在什么局面
3. 对手或压力来自哪里
4. 这部电影最值得讲的点是什么

### 标准模板

```text
这部电影讲的是一个________的人物，在________的局面里，被迫面对________的压力。表面上故事在讲________，但真正吸引人的，是主角如何在不断升级的冲突中做选择。电影最强的地方在于________，这也是这次解说最值得重点讲的部分。
```

### 示例

```text
这部电影讲的是一个极度聪明但也极度危险的人物，在一个被权力牢牢控制的地方，被迫面对来自强势对手的层层压制。表面上故事在讲双方斗法，但真正吸引人的，是主角如何在不断升级的冲突中一步步把局势拉回自己手里。电影最强的地方在于人物博弈和暗线试探，这也是这次解说最值得重点讲的部分。
```

## 9. 建议的发布测试方法

首批 3 期不要同时追求所有指标。

建议：

### 第 1 轮

- 每期先发 1 个版本
- 先只发一个平台
- 看完播率和评论

### 第 2 轮

把表现最好的一期改两个版本：

- 改开头句
- 改时长
- 改成 9:16

### 第 3 轮

确定一个稳定方向：

- 强剧情智斗
- 强悬念反转
- 强情绪共鸣

然后再批量做第 4 到第 10 期

---

## 10. 最务实的执行建议

如果你今天就要做，最推荐顺序是：

1. 先做第 1 期“强冲突人物局”
2. 用你最熟悉的一部电影
3. 只准备 3 段素材
4. 简介写清楚主线
5. 先生成 60 秒横版
6. 成功后再复制成第 2 期和第 3 期

因为对当前系统来说，最重要的不是选题多高级，而是：

- 输入要明确
- 素材要匹配
- 时长不要太贪
- 先稳定跑通
