# 运营可视化卡片规范

## 1. 目标
- 让控制台具备运营系统观感，而不只是信息列表。
- 形成可复用卡片协议，适配不同业务线（解说/短剧/电影/广告）。

## 2. 统一卡片结构
- 顶部：指标标题 + 维度标签（趋势/耗时/质量/预算）。
- 中部：核心数值（大字号）。
- 图层：迷你趋势图（线图或面积线图）。
- 底部：说明文案（口径说明）。

## 3. 颜色与语义
- 趋势：青蓝（cyan）。
- 耗时：金色（gold）。
- 成功率：浅绿（lime）。
- 成本：玫瑰红（rose）。

## 4. 指标定义
- 趋势图：近 7 天任务提交数。
- 任务耗时：已完成任务平均耗时（分钟）。
- 模型成功率：completed / (completed + failed)。
- 成本曲线：按 provider 单价估算的累计成本。

## 5. 组件落地
- 组件文件：frontend/components/common/OperationalInsightCards.tsx。
- 在控制台接入：frontend/app/dashboard/page.tsx。

## 6. 复用方式
- 每张卡片使用统一输入：
  - title
  - value
  - hint
  - trendText
  - tone
  - points
- points 格式：[{ label, value }]。
- 当业务口径变化时，只改数据计算层，不改展示层。

## 7. 扩展建议
- 新增“渠道转化率”“平均发布时延”“重试率”。
- 增加时间粒度切换（7天/30天/季度）。
- 支持按 provider 或业务线过滤。
